## About

Software engineering-focused Computer Science undergraduate at **IIIT Pune**, building production-oriented systems across **AI/ML, backend engineering, and full-stack development**.

My work focuses on designing systems where intelligent models are integrated with reliable software architecture — from **RAG pipelines and agentic workflows** to scalable APIs, relational data models, authentication, observability, and polished product interfaces.

I enjoy taking ambiguous product problems, decomposing them into well-defined engineering systems, and shipping solutions that balance **performance, maintainability, security, developer experience, and user value**.
